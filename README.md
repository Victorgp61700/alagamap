## 📌 Sobre o Projeto

O **AlagaMAP** foi desenvolvido no âmbito do programa **Trilhatec** para enfrentar um problema crítico vivenciado pela população de Recife: o alagamento recorrente de vias e avenidas em dias de fortes chuvas.

A proposta do sistema é transformar relatos individuais de moradores em informações públicas, preventivas e acessíveis em tempo real. Por meio da plataforma, motoristas, pedestres e usuários de transporte público podem checar trechos de risco, visualizar registros fotográficos das ruas e reportar novas ocorrências com precisão de localização.

---

## 🚀 Principais Funcionalidades

- **Mapeamento Interativo em Tempo Real:** Renderizado via Leaflet.js com marcadores coloridos baseados na gravidade do alagamento (Leve, Moderado, Grave/Intransitável).
- **Sistema de Login e Cadastro Simples:** Interface descomplicada para rápido acesso da população.
- **Envio de Alertas com Geolocalização:** Permite registrar ocorrências utilizando o GPS do dispositivo, adicionar descrições e anexar fotos tiradas na hora.
- **Filtros e Busca por Vias:** Pesquisa direcionada por bairros ou avenidas críticas (ex: *Av. Agamenon Magalhães*, *Av. Caxangá*).
- **Painel de Estatísticas no Header:** Exibição da quantidade de pontos ativos, alertas de emergência e nível de risco da região.
- **Quiz Rápido e Educativo:** Ferramenta interativa no topo do site com orientações de segurança e conscientização em dias de chuva.
- **Atalho de Emergência:** Acesso rápido para ligação com a **Defesa Civil (199)**.
- **Integração com Google Maps & Street View:** Direcionamento do ponto alagado diretamente para navegadores externos.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico:** Estruturação acessível das abas, formulários e modais.
- **CSS3 & Tailwind CSS:** Estilização responsiva em *dark mode* para excelente visualização em dispositivos móveis.
- **JavaScript (ES6+):** Lógica dinâmica de dados, manipuladores de eventos e geolocalização.
- **Leaflet.js:** API de mapas interativos leve e de alto desempenho.
- **Trello (Kanban) & GitHub:** Gestão de tarefas em equipe e versionamento colaborativo de código.

## 💻 Como Executar o Projeto Localmente

Como se trata de uma aplicação web (*Front-end Single Page*), não é necessária a instalação de dependências de backend ou servidores complexos.

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/victorgp61700/alagamap.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd alagamap
   ```

3. **Abra o arquivo principal no seu navegador:**
   - Dê um duplo clique no arquivo `index.html` ou utilize a extensão *Live Server* no VS Code.
